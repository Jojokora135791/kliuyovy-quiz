# Клюёвый квиз

Веб-приложение для проведения «Клюевого квиза» с друзьями. Весь контент
редактируется в одном месте (`/editor`), доска и переходы собираются сами — руками
расставлять гиперссылки между слайдами больше не нужно.

Стек: Vite + React + TypeScript, без бэкенда и базы данных. Весь квиз — один JSON-файл
в `/public/quizzes`, медиа — файлы в `/public/media`. Прогресс игры и счёт хранятся
в localStorage браузера.

## Как это устроено

- **`/`** — табло для зрителей (открывается на ТВ/проекторе).
- **`/host`** — панель ведущего: с неё задаются команды, идёт навигация по квизу,
  таймер и начисление баллов. Открывается в соседней вкладке/окне **того же браузера
  на том же ноутбуке** — синхронизация с табло идёт через `BroadcastChannel`, без
  сервера. Если табло будет на другом устройстве (не вкладка, а отдельный компьютер/
  смарт-ТВ по сети), эта синхронизация не сработает — тогда потребуется добавить
  бэкенд (например WebSocket) отдельным этапом.
- **`/editor`** — редактор содержимого квиза. Публичный роут без пароля (сознательный
  выбор для первого этапа) — не делись ссылкой с теми, кто не должен видеть ответы
  заранее.

## Структура игры «Клюевый квиз 3.0. Autumn Time»

Квиз — `public/quizzes/autumn-time.json`. Сейчас это болванка: темы расставлены,
вопросы-заглушки «— заполнить» надо заменить в `/editor`.

**Комнаты.** В квизе две комнаты — «Хеллоуин» и «Кацаб». Ведущий выбирает комнату
на старте в `/host`. Раунд с полем `roomId` играется только в своей комнате, раунд
без него — во всех. Сейчас отличается только Раунд 1 (разные списки треков).

| Раунд | Механика (`type`) | Как играется |
|---|---|---|
| 1 | `music` | Треки по очереди. Отвечает команда, чья очередь; «Мимо» — ход следующей. +1 за угаданного автора, +1 за трек/исполнителя/напев. |
| 2.1, 2.2 | `trickOrTreat` | Доска «тема × номер». Перед каждым вопросом команды выбирают 🍬 Сладость (+1 / 0 / 0) или 💀 Гадость (+3 / −2 / −1 за верно / неверно / пусто). Очки настраиваются в раунде. |
| Финал | `casino` | «Казино Рояль»: 5 тем — 5 вопросов по очереди (в каждой теме 1 вопрос). Перед каждым вопросом команды видят тему и ставят сколько угодно баллов (на табло суммы скрыты), потом вопрос; верно — +ставка, неверно — −ставка. |

Порядок для ведущего — всё по Space: правила → доска → (выбор сладость/гадость) →
вопрос → ответ → «Засчитать баллы» → дальше. Отметки «верно/мимо» и выбор команд
ставятся в правой панели `/host`, там же шпаргалка с ответом. Начисление можно
отменить, счёт можно поправить вручную кнопками ± у команд.

## Как редактировать контент

1. Открой `/editor`: раунды, темы, вопросы, комнаты, оформление, звуки.
   Черновик автосохраняется в localStorage.
2. Нажми «Экспорт JSON» и положи файл в `public/quizzes/autumn-time.json` —
   без бэкенда редактор не может сам писать на диск.
3. Новый квиз — добавь файл в `public/quizzes/` и запись в `public/quizzes/index.json`.

## Музыка на выборе вопроса

Пока команды выбирают вопрос (доска, «Сладость или гадость», ставки финала), на `/host`
играет плейлист Spotify; на вопросе и ответе он встаёт на паузу и потом продолжается.
Ссылка задаётся в `/editor` → настройки квиза → «Звуки». Войди в Spotify в том же браузере,
иначе вместо полных треков могут играть короткие превью.

## Как добавить медиа (картинки, аудио, видео, YouTube)

- **Файл с компьютера**: положи его в `public/media/` (например
  `public/media/pumpkin.jpg`) и укажи в поле медиа путь `/media/pumpkin.jpg`.
- **Внешний URL**: вставь ссылку на картинку/аудио/видео как есть.
- **YouTube**: вставь обычную ссылку (`https://youtu.be/...` или
  `https://www.youtube.com/watch?v=...`), при необходимости задай `start`/`end`
  в секундах — ролик покажется только нужным фрагментом.

Фон можно задать на уровнях квиз → комната → раунд → вопрос, звук — квиз → вопрос, более
конкретный уровень переопределяет общий.

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173` (или другом свободном порту). Открой `/host`
и `/` в двух вкладках браузера, чтобы проверить синхронизацию перед игрой.

## Деплой на Vercel

1. Залей проект в GitHub (или любой git-провайдер, который поддерживает Vercel).
2. На [vercel.com](https://vercel.com) → **Add New Project** → выбери репозиторий.
   Vercel сам определит фреймворк Vite, ничего менять не нужно (команда сборки
   `npm run build`, папка `dist`).
3. Деплой на бесплатном тарифе работает без ограничений для этого проекта —
   бэкенда и БД нет, только статика.
4. После деплоя: открой `<твой-домен>.vercel.app/host` на ноутбуке ведущего и
   `<твой-домен>.vercel.app/` на той же машине во второй вкладке, которую выводишь
   на проектор (например через расширение рабочего стола на второй монитор).
5. Чтобы обновить контент после деплоя — отредактируй JSON через `/editor`,
   экспортируй, замени файл в `public/quizzes/` в репозитории и запушь:
   Vercel передеплоит автоматически.

## Известные ограничения первого этапа

- `/editor` не защищён паролем — доступен всем, кто знает ссылку.
- Синхронизация ведущий↔табло работает только в пределах одного браузера на
  одном устройстве (`BroadcastChannel`). Два разных устройства по сети — не
  поддерживается без отдельного бэкенда.
- Экспорт из редактора скачивает файл локально — чтобы изменения попали в
  задеплоенную версию, файл нужно руками положить в `public/quizzes/` и
  задеплоить заново.
